## 一、5 分钟快速理解

### GameForge 是什么？

一套**游戏开发协作框架**，让你（不会编程的产品经理）能指挥 AI 团队把游戏做出来。

**核心思路**：
```
你提需求 → 我派发 AI 团队（8 个角色）→ 他们分工完成 → 交给你审核 → 你确认 → 完成
```

**你的工作**：
- 定方向（做什么游戏）
- 做决策（A 方案还是 B）
- 审核产出（合不合理）
- 试玩反馈（爽不爽）

**AI 团队的工作**：
- 设计玩法、系统、数值
- 写代码
- 找美术素材
- 测试验证

## 七、配置表驱动 — 为什么你能参与

传统做法：每加一把武器，程序要写一段代码 → 你看不懂，无法参与。

**GameForge 做法**：武器的属性写在 JSON 配置表里 → 你能看懂，能改数字。

**示例**：
```json
{
  "id": "weapon_vampire_blade",
  "display_name": "吸血之刃",
  "damage": 22,
  "attack_speed": 1.5,
  "special_effect": "lifesteal 15%"
}
```

你能直接看懂这把剑伤害 22、攻速 1.5、吸血 15%。你想调成吸血 20%，直接改数字就行。

**这就是为什么"不会编程也能做游戏"——内容是数据，不是代码。**

## 九、常见问题

**Q：我真的不用写代码吗？**
A：真的。你的工作是提需求、做决策、试玩反馈。代码全部由 AI 程序完成。

**Q：我不懂 JSON 配置表怎么办？**
A：JSON 很简单，就是"键值对"。你看几个例子就懂了，而且我会帮你生成，你只需要改数字。

**Q：AI 做错了怎么办？**
A：测试 AI 会发现 Bug，我会派发程序修复。你发现不对也可以直接告诉我。

**Q：我想改游戏方向，可以吗？**
A：可以。你是制作人，随时能改方向。我会更新 GDD 和 decisions.md 记录变更。

**Q：配置表在哪里？我能自己改吗？**
A：在 `project/config/` 文件夹。你可以自己改，改完告诉我重新测试即可。

**Q：3 个月真的能做完吗？**
A：如果严格控制第一版范围（1 职业、1 副本、20 装备），是可行的。关键是快速验证，别追求完美。
