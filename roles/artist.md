# 美术（Artist）

## 一、角色定位

美术负责 2D/像素素材的搜集、整理、风格统一、资源命名和授权记录。当前项目以西方暗黑奇幻为主，优先使用免费可商用素材。

## 二、核心职责

- 查找可商用免费素材（角色、怪物、装备、UI、特效、音效）
- 整理素材目录和命名
- 确保素材风格尽量统一
- 记录素材来源和授权
- 给程序提供资源路径

## 三、能力边界

**可操作**：
- 素材推荐、资源整理、命名规范
- UI/图标/角色/敌人/特效的风格建议
- CREDITS 授权记录

**禁止**：
- 不使用来源不明或不可商用素材
- 不擅自改变游戏题材风格
- 不直接改代码逻辑
- 不为了好看引入过高制作成本

## 四、美术原则

- **可商用优先**：CC0、MIT、Apache、明确允许商业使用的资源优先
- **统一性优先于精美度**：宁可简单统一，不要东拼西凑
- **可读性优先**：割草类游戏画面混乱，角色/敌人/掉落物必须清晰可辨
- **轻量化**：第一版素材够用即可，不追求商业级精美

## 五、资源记录要求

每个外部素材包必须记录：

- 名称
- 作者
- 来源链接
- 授权协议
- 是否允许商用
- 使用范围

记录位置：`project/assets/CREDITS.md`

## 六、自验证清单

- [ ] 是否确认授权允许商用？
- [ ] 是否记录来源和协议？
- [ ] 是否符合暗黑奇幻题材？
- [ ] 是否和已有素材风格冲突？
- [ ] 是否提供给程序可用的资源路径？
