## 🎮 启动测试步骤

### 1. 打开 Godot 项目
```bash
# 项目路径
D:\桌面\CC工具\gm\project\src\project.godot
```

1. 启动 **Godot 4** 编辑器
2. 点击 **"导入"** 或 **"Import"**
3. 浏览到上述路径，选择 `project.godot`
4. 点击 **"导入并编辑"**

### 3. 完整流程测试

#### 流程 A：主菜单 → 职业选择 → 主城 → 战斗
1. **主菜单**：点击"开始游戏"
2. **职业选择**：选择战士/游侠/法师
3. **主城**：
   - 查看金币（初始0）
   - 查看5项属性强化（全0级）
   - 查看副本列表（地穴遗迹 T1/T2/T3）
   - 点击 **T1** 进入战斗
4. **战斗场景**：
   - 玩家可用 **WASD** 移动
   - 按 **Tab** 切换自动/手动攻击
   - 敌人自动生成并追踪玩家
   - 击杀敌人获得经验和金币

#### 流程 B：升级系统测试
1. 击杀敌人到经验条满
2. 弹出技能选择界面（3选1）
3. 选择一个技能
4. 技能效果应用（移速/生命/伤害）
5. 继续战斗

#### 流程 C：装备掉落测试
1. 击杀足够多敌人触发3%掉落
2. 金色方块飞向玩家
3. 接触后弹出装备对比界面
4. 查看属性对比（绿色↑红色↓）
5. 按 **E** 装备 或 **Q** 丢弃

#### 流程 D：死亡测试
1. 让敌人攻击玩家至血量为0
2. 弹出 GameOver 界面
3. 显示存活时间、击杀数、金币
4. 点击"再来一局"重新开始

## 🐛 如果遇到问题

### 问题：敌人不生成
**检查**：
1. Output 窗口是否有 `[EnemySpawner] 加载波次组` 日志
2. `config/waves.json` 是否正确加载

### 问题：音效不播放
**检查**：
1. `assets/audio/sfx/` 目录是否有 `.ogg` 文件
2. Output 是否有 `[AudioManager] 找不到音效` 警告

### 问题：装备不掉落
**检查**：
1. 3%概率需要击杀多个敌人（平均33个掉1件）
2. Output 是否有装备系统错误

### 问题：主城界面报错
**检查**：
1. `config/dungeons.json` 和 `config/balance.json` 是否加载成功
2. `GameState` 是否初始化
