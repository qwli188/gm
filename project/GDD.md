# 游戏设计文档（GDD）

> Game Design Document for 暗黑奇幻 Loot ARPG（DarkLoot）
> 版本：0.1.0 | 更新日期：2026-06-02

---

## 一、游戏概述

### 1.1 核心概念

一款西方奇幻题材的 Loot ARPG，玩家进入地牢副本，击杀怪物获得装备和经验，通过装备词缀和技能组合搭建不同流派（Build），在局内变强后挑战 Boss，阵亡或通关后回到城镇用金币永久强化角色，然后挑战更高难度。

**一句话**：像暗黑破坏神一样刷装备搭配构筑，像吸血鬼幸存者一样轻松割草。

### 1.2 核心卖点

**装备构筑深度** —— 通过装备词缀、技能联动、流派标签（tags）组合出多种可行的 Build。

### 1.3 目标体验

- **放松**：自动攻击模式解放双手，碎片时间可玩
- **爽感**：满屏击杀、装备掉落、数值暴涨
- **成就感**：凑齐套装、通关高难度、解锁新内容
- **快感**：装备词缀触发连锁反应、流派成型的化学反应

## 二、核心玩法

### 2.1 三层循环

```
┌─ 局内循环（单局 10-20 分钟）──────────────┐
│ 进副本 → 打怪 → 升级三选一 → 掉装备穿上  │
│ → 越来越强 → Boss 战 → 通关/阵亡        │
└─────────────────────────────────────┘
           ↓ 每局带回金币和装备
┌─ 局外循环（永久成长）─────────────────┐
│ 仓库存装备 → 金币升级基础属性          │
│ → 解锁新副本/职业 → 挑战更高难度       │
└─────────────────────────────────────┘
           ↓ 追求不同 Build
┌─ 长期循环（重玩性）───────────────────┐
│ 不同职业 × 不同装备词缀 × 不同技能组合 │
│ → 走出火焰流/吸血流/召唤流等流派      │
│ → 挑战排行榜/深渊难度（后续版本）     │
└─────────────────────────────────────┘
```

### 2.2 战斗系统

**控制方式**：
- **手动模式**：WASD 移动，鼠标控制攻击方向，技能键释放技能
- **自动模式**：WASD 移动，角色自动攻击最近敌人，技能自动释放
- 玩家可随时切换模式（快捷键 Tab）

**攻击机制**：
- 武器决定攻击类型（近战挥砍/远程弹道/魔法 AOE）
- 装备词缀影响攻击效果（吸血/点燃/连锁/穿透）
- 技能增强或改变攻击方式

**成长机制**：
- 击杀怪物获得经验，升级时从 3-4 个随机技能/强化中选一个
- 怪物掉落装备，穿上后立即生效
- 装备带随机词缀，词缀之间能联动触发流派

## 三、核心系统

### 3.1 装备系统

**装备槽**：
- 武器（决定攻击类型）
- 护甲（增加防御和生命）
- 饰品（特殊效果）

**稀有度**：
- 普通（白）：纯基础属性，0 词缀槽
- 优秀（绿）：1 词缀槽
- 稀有（蓝）：2 词缀槽
- 史诗（紫）：3 词缀槽
- 传奇（橙）：2 词缀槽 + 固定特效（定义流派）

**词缀系统** —— 构筑深度的核心：
- 词缀分属性类（+伤害、+暴击）和效果类（吸血、点燃、连锁）
- 词缀带标签（tags），同标签词缀能联动触发套装效果
- 示例流派：
  - **火焰流**：火焰伤害词缀 + 点燃效果 + 火焰技能 → 持续燃烧 AOE
  - **吸血流**：吸血词缀 + 高攻速装备 → 贴脸不死割草
  - **召唤流**：召唤词缀 + 召唤技能 + 召唤物增益词缀 → 宠物大军

### 3.2 技能系统

**获取方式**：局内升级三选一

**技能类型**：
- **主动技能**：发射弹道、召唤、AOE 爆发
- **被动技能**：属性增益、触发效果
- **强化技能**：升级已有技能（多发、伤害、范围）

**技能联动**：技能也带 tags，与装备词缀联动（火焰技能 + 火焰装备 = 流派成型）

### 3.3 敌人与副本系统

**敌人类型**：
- 普通怪：成群、血薄、提供割草爽感
- 精英怪：血厚、特殊能力、掉落更好
- Boss：阶段机制、独特攻击模式、副本记忆点

**副本结构**：
- 每个副本 10-20 分钟
- 怪物按波次生成（开局轻松 → 中段渐强 → 精英突袭 → Boss 战）
- 每个副本有独特机制（周期黑暗、熔岩地板、毒雾）
- 难度分层：同一副本有多个难度，装备越好能打越高，掉落越好

### 3.4 局外成长系统

**金币系统**：
- 怪物掉金币，阵亡也能带回
- 用金币在城镇升级基础属性（生命、伤害、移速等）
- 成本递增，提供长期目标

**解锁系统**：
- 通关副本解锁新副本/新装备
- 达成成就解锁新职业/新技能

## 四、美术与音效

### 4.1 美术风格

- **2D 像素风格**（16x16 或 32x32）
- **西方奇幻暗黑**：地牢、骷髅、恶魔、暗色调
- **参考**：Halls of Torment、Enter the Gungeon、Vampire Survivors

### 4.2 UI 设计

- 血条、经验条（屏幕上方）
- 装备栏、技能栏（屏幕下方）
- 升级选择界面（暂停游戏，三选一卡牌式）
- 掉落装备弹窗（品质颜色区分）

### 4.3 音效

- 攻击音效（挥砍、法术、爆炸）
- 掉落音效（根据品质不同音调）
- 升级音效（正反馈）
- 背景音乐（暗黑风，循环播放）

## 五、第一版范围（MVP）

### 5.1 必须有

**内容量**：
- 1 个职业（战士，近战）
- 1 个副本（枯骨地穴，亡灵主题）
- 20 件装备（武器 8、护甲 6、饰品 6）
- 10 个词缀（吸血、火焰伤害、攻速等）
- 10 个技能（5 主动、5 被动）
- 5 种普通怪 + 2 种精英 + 1 个 Boss
- 1 个波次配置（开局 → 中段 → 精英 → Boss）
- 5 项局外强化属性

**系统功能**：
- 角色移动 + 手动/自动攻击切换
- 装备掉落、穿戴、属性生效
- 词缀随机、效果触发
- 升级三选一
- 局外金币升级
- 存档/读档

### 5.2 第一版不做

- 多职业
- 多副本
- 套装系统（先做词缀联动）
- 天赋树
- 排行榜/竞技
- 多人联机

## 六、关键设计原则

1. **配置表驱动**：所有内容数据化，加内容 = 填表
2. **爽感优先**：数值宁可偏强，不要让玩家觉得弱
3. **构筑多样**：避免唯一最优解，多种流派可行
4. **快速验证**：先做能玩的，再加深度
5. **失败有收获**：阵亡也能带回金币，驱动"再来一局"

---

## 七、差异化竞争

**vs 吸血鬼幸存者**：
- ✅ 我们有装备掉落和词缀系统（更深的构筑）
- ✅ 我们有局外永久强化（更长的成长线）
- ✅ 我们有副本机制和 Boss（更多记忆点）

**vs 暗黑破坏神**：
- ✅ 我们更轻松（自动攻击、单局短）
- ✅ 我们更快节奏（局制，不肝）
- ✅ 我们更适合个人开发（配置表驱动）

**vs Halls of Torment**：
- ✅ 我们的词缀联动更深（标签系统驱动流派）
- ✅ 我们支持手动和自动双模式（覆盖更广玩家）

## 八、风险与应对

| 风险 | 应对 |
|------|------|
| 装备构筑深度难以平衡 | 数值策划持续调整，测试反馈驱动 |
| 3 个月时间不够 | 严格控制第一版范围，MVP 优先 |
| 美术素材不统一 | 选定风格，只用该风格的免费素材 |
| 玩法不够有趣 | 快速原型验证，不行就调整 |
