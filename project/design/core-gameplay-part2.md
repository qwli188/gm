# DarkLoot ARPG - 核心玩法详细设计（第二部分）

> 操作手感、敌人AI、副本流程、掉落机制

---

## 二、操作手感

### 2.1 移动系统

**移动速度**：
- 基础：200 像素/秒
- 可被词缀/技能提升（如+15%移速 → 230像素/秒）
- 移速上限：400（防止过快失控）

**移动惯性**：
- **无惯性**（即时响应）
- 按下WASD立即达到最大速度
- 松开WASD立即停止

**设计意图**：割草游戏需要灵活走位，不要惯性

**碰撞**：
- 玩家与敌人碰撞：玩家被轻微击退，不能穿过
- 玩家与墙壁碰撞：停止移动，不能穿墙
- 玩家与掉落物：自动拾取（无需按键）

---

### 2.2 攻击系统

#### 手动模式攻击

**输入**：鼠标左键

**方向**：鼠标指针相对玩家的方向

**前摇**：0.1秒（挥剑动作开始）

**判定帧**：前摇结束时判定伤害

**后摇**：0.2秒（挥剑动作结束，此时可以移动但不能攻击）

**攻击距离**：
- 近战武器：50像素
- 远程武器：500像素（发射弹道）

**连击**：
- 连续按鼠标左键可以连击
- 连击之间间隔由攻速决定
- 攻速1.0 = 1秒1次 → 连击间隔1秒

---

#### 自动模式攻击

**索敌范围**：屏幕内（约800像素半径）

**索敌优先级**：
1. Boss（最高优先级）
2. 精英怪
3. 最近的普通怪

**攻击频率**：由攻速决定，自动连续攻击

**方向**：自动朝向目标

---

### 2.3 受击反馈

**玩家受击时**：
- 播放受击音效
- 角色闪红（0.1秒）
- 轻微震屏（5像素抖动）
- 无敌帧0.5秒（防止瞬间暴毙）
- 生命条减少动画

**敌人受击时**：
- 伤害数字弹出（白色=普通，黄色=暴击）
- 敌人闪白（0.05秒）
- 轻微击退（5像素，防止贴脸卡住）
- 血条减少

---

### 2.4 技能释放

**技能CD机制**：
- 每个技能独立CD
- CD中的技能图标变暗 + 倒计时显示
- CD完成后高亮并播放音效

**技能释放手感**：
- 按下技能键立即释放（无延迟）
- 技能动画简洁（不超过0.5秒）
- 技能释放时不打断移动（可以边走边放）

**技能类型手感**：
- **弹道技能**（火球术）：发射弹道，飞行速度500像素/秒
- **近战技能**（旋风斩）：以玩家为中心，360度范围攻击
- **被动技能**：无手感，持续生效

---

### 2.5 无敌帧设计

**什么是无敌帧**：
受击后短暂时间内不会再次受到伤害

**数值**：
- 受击后0.5秒无敌
- 视觉反馈：角色闪烁（透明度变化）

**设计意图**：
- 防止被多个敌人同时攻击瞬间暴毙
- 给玩家反应时间脱离危险

**特例**：
- 持续伤害（毒雾、熔岩）不触发无敌帧
- Boss 的超重击可以打破无敌帧（后续版本）

## 三、敌人 AI

### 3.1 普通怪 AI

#### 骷髅兵（近战追击型）

**行为逻辑**：
```
1. 如果玩家在视野范围内（600像素）：
   → 追击玩家
2. 如果距离玩家 < 攻击距离（30像素）：
   → 停止移动，执行攻击
3. 否则：
   → 随机游荡
```

**追击速度**：60像素/秒（略慢于玩家）

**攻击前摇**：0.3秒（挥剑动作，玩家可以躲避）

**攻击判定**：碰撞判定（接触即伤害）

**设计意图**：玩家可以风筝，但如果被围住很危险

---

#### 僵尸（坦克型）

**行为逻辑**：
```
同骷髅兵，但移动更慢
```

**追击速度**：40像素/秒（很慢）

**血量**：50（骷髅兵的2.5倍）

**设计意图**：慢速肉盾，混在骷髅兵中制造节奏变化

---

### 3.2 精英怪 AI

#### 骸骨骑士（冲锋型）

**行为逻辑**：
```
阶段1：像骷髅兵一样追击
阶段2：距离玩家 100-200 像素时触发冲锋
  → 播放蓄力动画（0.5秒，红色光圈提示）
  → 朝玩家方向冲锋（速度300像素/秒）
  → 冲锋距离：200像素
  → 命中玩家造成高伤害（普通攻击的2倍）
  → 冲锋CD：5秒
```

**设计意图**：制造威胁感，玩家需要走位躲避

**视觉反馈**：
- 蓄力时红色光圈
- 冲锋时拖尾特效
- 命中时屏幕震动

---

### 3.3 Boss AI

#### 白骨领主（召唤 + 地刺型）

**行为模式**：
```
阶段1（血量100% - 50%）：
  - 每10秒召唤2个骷髅兵
  - 每15秒在玩家脚下生成地刺（范围50像素）
    - 提示：红色圆圈（1秒）
    - 判定：圆圈消失时造成伤害
  - 缓慢追击玩家

阶段2（血量50% - 0%，狂暴）：
  - 召唤频率提升：每5秒召唤3个骷髅兵
  - 地刺频率提升：每10秒
  - 移动速度提升20%
  - 播放狂暴动画和台词："我曾是王……现在……只是怪物……"
```

**设计意图**：
- 多阶段制造记忆点
- 召唤小怪制造混乱（考验玩家清怪能力）
- 地刺考验走位

**弱点机制**（后续版本）：
- 召唤时有0.5秒硬直（可以趁机输出）

---

### 3.4 敌人生成规则

**波次生成**（参考 waves.json）：

**开局（0-2分钟）**：
- 每3秒生成1个骷髅兵
- 最多同时存在10个

**中段（2-5分钟）**：
- 每2秒生成1个骷髅兵
- 每5秒生成1个僵尸
- 最多同时存在30个

**高潮（5-8分钟）**：
- 每1.5秒生成1个骷髅兵
- 每4秒生成1个僵尸
- 每30秒生成1个精英（骸骨骑士）
- 最多同时存在50个

**Boss战（10分钟）**：
- 清空所有小怪
- 生成Boss
- Boss战期间暂停小怪生成（Boss 会召唤）

**性能阀门**：
- 屏幕内最多50个敌人
- 超过数量停止生成
- 敌人死亡后才继续生成

## 四、副本流程

### 4.1 副本时长

**目标时长**：10-15分钟

**时间分配**：
- 0-2分钟：热身（捡第一波装备、选第一批技能）
- 2-8分钟：强度递增（怪越来越多、玩家越来越强）
- 8-10分钟：精英突袭（制造小高潮）
- 10-15分钟：Boss战

---

### 4.2 副本机制示例

#### 枯骨地穴：周期性黑暗

**机制**：
- 每60秒触发一次黑暗
- 黑暗持续8秒
- 黑暗期间：
  - 屏幕变暗（视野缩小到120像素）
  - 敌人在黑暗中隐身（只能看到轮廓）
  - 怪物移动速度+20%

**视觉反馈**：
- 倒计时UI（"黑暗来临：10秒"）
- 屏幕边缘变暗特效
- 背景音乐变压抑

**设计意图**：
- 制造紧张感
- 考验玩家记忆敌人位置
- 副本独特记忆点

## 五、掉落机制

### 5.1 掉落触发

**怪物死亡时**：
- 100%掉落金币（数量由 balance.json 决定）
- 3%概率掉落装备
- Boss 50%掉落装备，保底稀有以上

**掉落位置**：
- 敌人死亡位置
- 掉落物自动飞向玩家（0.5秒）
- 玩家靠近自动拾取（无需按键）

---

### 5.2 品质权重

**参考 balance.json**：
```json
{
  "rarity_weights": {
    "common": 60,
    "uncommon": 25,
    "rare": 10,
    "epic": 4,
    "legendary": 1
  }
}
```

**实际概率**：
- 普通（白）：60%
- 优秀（绿）：25%
- 稀有（蓝）：10%
- 史诗（紫）：4%
- 传奇（橙）：1%

**难度加成**：
- 困难难度：稀有以上权重 +50%
- 专家难度：史诗以上权重 +100%
- 深渊难度：传奇权重 +200%

---

### 5.3 词缀随机规则

**词缀槽数量**（由装备稀有度决定）：
- 普通：0槽
- 优秀：1槽
- 稀有：2槽
- 史诗：3槽
- 传奇：2槽 + 固定词缀

**词缀抽取**：
- 从 affixes.json 的词缀池随机
- 每个词缀有权重（tier 越高越稀有）
- 同一装备不会有重复词缀
- 词缀必须适用于该装备槽（applicable_slots）

**示例**：
```
掉落一把稀有铁剑：
1. 稀有 = 2个词缀槽
2. 从词缀池抽取2个词缀
3. 第一次抽到：吸血（tier 2）
4. 第二次抽到：攻速+20%（tier 1）
5. 生成装备：铁剑（稀有）+ 吸血 + 攻速
```

---

### 5.4 掉落视觉反馈

**装备掉落时**：
- 播放掉落音效（品质越高音调越高）
- 装备发光特效（颜色对应品质）
- 屏幕边缘提示（"稀有装备掉落！"）
- 传奇掉落时屏幕闪光

**拾取时**：
- 播放拾取音效
- 装备飞向玩家动画
- UI弹窗显示装备信息

## 六、设计原则总结

### 6.1 爽感优先

- 攻击立即响应（无延迟）
- 伤害数字清晰可见
- 暴击有明显反馈
- 掉落有满足感

### 6.2 操作友好

- 手动/自动双模式（覆盖不同玩家）
- 移动无惯性（精准走位）
- 无敌帧保护（不会瞬间暴毙）
- 掉落物自动拾取（不打断战斗）

### 6.3 难度合理

- 敌人AI简单但有威胁
- 精英/Boss有明显提示（可以躲避）
- 数值递增温和（不会突然暴击暴毙）
- 失败能带回一半金币（不白玩）
