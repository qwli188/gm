## 一、战斗机制

### 1.1 控制模式

#### 手动模式（Manual Mode）

**输入**：
- **WASD**：8方向移动
- **鼠标方向**：决定攻击方向（相对玩家位置）
- **鼠标左键**：普通攻击
- **Q/E/R/F**：技能 1-4
- **空格**：闪避/冲刺（后续版本）
- **Tab**：切换自动/手动模式

**特点**：
- 精准控制攻击方向
- 适合硬核玩家
- 需要操作和走位
- 打击感更强

---

#### 自动模式（Auto Mode）

**输入**：
- **WASD**：8方向移动
- **攻击**：自动攻击最近敌人（无需按键）
- **技能**：自动释放（CD 好了就放）
- **Tab**：切换回手动模式

**特点**：
- 解放双手，只需走位
- 适合休闲玩家
- 适合移动端（后续）
- 刷装备时很爽

**自动索敌规则**：
1. 优先攻击屏幕内最近的敌人
2. 如果有精英/Boss，优先攻击精英/Boss
3. 攻击方向自动朝向目标

### 1.2 伤害计算公式

#### 基础伤害公式

```
最终伤害 = (基础伤害 + 附加伤害) × 伤害增益 × 暴击倍率 × 抗性系数
```

**详细拆解**：

**1. 基础伤害**
```
基础伤害 = 武器伤害 + 局外永久伤害加成
```

**2. 附加伤害**
```
附加伤害 = Σ 词缀伤害 + Σ 技能伤害
例：火焰词缀 +8，点燃词缀 +5 → 附加伤害 = 13
```

**3. 伤害增益**（百分比加成，乘法叠加）
```
伤害增益 = (1 + 词缀增益1) × (1 + 词缀增益2) × ...
例：+20%伤害 × +15%伤害 = 1.2 × 1.15 = 1.38（总增益38%）
```

**4. 暴击倍率**
```
if (随机数 < 暴击率):
    暴击倍率 = 基础暴击倍率 × (1 + 暴击伤害加成)
else:
    暴击倍率 = 1.0

基础暴击倍率 = 1.5（可被词缀/技能提升）
```

**5. 抗性系数**（边际递减）
```
抗性系数 = 1 - (敌人护甲 / (敌人护甲 + 100))

例：
- 护甲 0 → 抗性系数 = 1.0（无减伤）
- 护甲 50 → 抗性系数 = 0.67（减伤33%）
- 护甲 100 → 抗性系数 = 0.5（减伤50%）
- 护甲 300 → 抗性系数 = 0.25（减伤75%）
```

**设计意图**：护甲越高，继续堆护甲的收益越低（防止无敌坦克）

---

#### 示例计算

**场景**：战士穿吸血之刃攻击骷髅兵

**玩家数据**：
- 武器伤害：22
- 局外永久伤害：+10（升级了5次）
- 词缀：火焰伤害+8，伤害+20%
- 暴击率：8%
- 暴击倍率：1.5

**敌人数据**：
- 护甲：0

**计算**：
```
基础伤害 = 22 + 10 = 32
附加伤害 = 8（火焰词缀）
伤害增益 = 1.2（+20%词缀）
暴击倍率 = 1.0（假设未暴击）
抗性系数 = 1.0（护甲0）

最终伤害 = (32 + 8) × 1.2 × 1.0 × 1.0 = 48
```

**如果暴击**：
```
最终伤害 = (32 + 8) × 1.2 × 1.5 × 1.0 = 72
```

### 1.3 暴击机制

**暴击判定**：
- 每次攻击时，生成随机数 [0, 1)
- 如果随机数 < 暴击率，触发暴击
- 暴击时伤害 × 暴击倍率（默认1.5）

**暴击视觉反馈**：
- 伤害数字更大、颜色变黄
- 屏幕轻微震动
- 播放特殊音效

**暴击率上限**：75%（防止100%暴击破坏平衡）

**暴击倍率**：
- 基础：1.5倍
- 可被技能/词缀提升（如+50%暴击伤害 → 2.0倍）

---

### 1.4 词缀效果触发逻辑

#### 吸血（Lifesteal）

**触发时机**：造成伤害时

**效果**：
```
回复生命 = 造成伤害 × 吸血百分比

例：造成48伤害，吸血15% → 回复 7.2 生命（取整为7）
```

**视觉反馈**：
- 绿色数字飘向玩家
- 生命条增加动画

---

#### 点燃（Ignite）

**触发时机**：攻击命中敌人时，概率触发

**效果**：
```
每秒造成 X 点火焰持续伤害，持续 Y 秒

例：点燃词缀 5 DPS 持续 3 秒 → 总伤害 15
```

**机制**：
- 点燃可叠加（多次攻击多次点燃）
- 每个点燃独立计时
- 敌人身上显示火焰特效

**设计意图**：适合打血厚怪物，持续伤害流

---

#### 连锁闪电（Chain Lightning，后续版本）

**触发时机**：攻击命中敌人时

**效果**：
```
攻击跳跃到附近 N 个敌人，每次跳跃伤害递减

例：初始伤害 50，跳跃2次，递减20%
- 第一个敌人：50
- 第二个敌人：40（50 × 0.8）
- 第三个敌人：32（40 × 0.8）
```

**视觉反馈**：闪电链条连接敌人

---

#### 穿透（Pierce，后续版本）

**触发时机**：发射弹道时

**效果**：
```
弹道穿过敌人不消失，继续飞行

例：穿透2次，最多命中3个敌人
```

**设计意图**：适合远程武器，清理成群敌人

---

### 1.5 攻速机制

**攻击速度（Attack Speed）**：每秒攻击次数

**基础攻速**：1.0（每秒1次）

**攻速倍率计算**：
```
最终攻速 = 基础攻速 × (1 + 攻速加成1) × (1 + 攻速加成2) × ...

例：基础1.0，装备+20%，词缀+30%
最终攻速 = 1.0 × 1.2 × 1.3 = 1.56（每秒1.56次攻击）
```

**攻速上限**：3.0（防止过快导致动画错乱）

**攻速对吸血流的影响**：
- 攻速越高，每秒吸血次数越多
- 配合吸血词缀 = 强力续航
