# DarkLoot v3 - 副本流程设计

## 设计原则

### 3阶段流程
1. **地形探索** (30-60秒)
   - 玩家进入副本后先观察地形
   - 有障碍物、宝箱、互动元素
   - 小怪分散在地图各处

2. **波次战斗** (2-3分钟)
   - 3-5波小怪，每波间隔15-30秒
   - 难度递增：数量↑ + 精英怪出现
   - 利用地形优势（掩体、陷阱）

3. **Boss战** (1-2分钟)
   - Boss登场动画（从地底/天空/传送门出现）
   - 区域专属技能 + 环境互动
   - 阶段转换（血量50%/25%触发机制）

## 7区域副本设计（各取第1个副本作为范例）

### 1. dungeon_crypt_1：安罗斯王陵·入口

**地形特色**：
- **布局**：矩形墓室（800x600），中央有石棺祭坛
- **障碍物**：
  - 4个石柱（玩家可绕柱躲避）
  - 破碎墓碑散落（阻挡移动）
- **互动元素**：
  - 2个骨堆（点击F获得小额金币）
  - 墙壁骷髅灯（照亮雾区）
- **环境机制**：每30秒触发死亡之雾（紫色雾气全屏，5秒）

**波次战斗**：
- **第1波** (15秒后)：4只骷髅兵 - 分散在4个角落
- **第2波** (30秒后)：6只骷髅兵 + 2只骷髅射手
- **第3波** (45秒后)：8只骷髅兵 + 1只骷髅骑士（精英）
- **触发条件**：前一波全灭 + 等待时间

**Boss战**：
- **出现方式**：第3波清理后，中央石棺打开，Boss"腐朽领主"爬出
- **登场台词**："愚者...竟敢扰吾长眠..."
- **专属技能**：
  - 王座审判（飞天+8方位骨刺）
  - 死亡之息（扇形吐息）
- **阶段转换**：
  - 50%血量：召唤4只骷髅骑士
  - 25%血量：死亡之雾常驻（无间隔）

### 2. dungeon_forge_1：熔岩铸造厂·矿井

**地形特色**：
- **布局**：工字形矿道（1000x400），中央有熔炉
- **障碍物**：
  - 矿车轨道（玩家可站上躲避地面伤害）
  - 3个大熔炉（Boss战时会喷发岩浆）
- **互动元素**：
  - 矿石堆（F键采集，获得材料）
  - 墙壁开关（关闭附近熔炉）
- **环境机制**：地面随机冒岩浆池（持续3秒，50 DPS）

**波次战斗**：
- **第1波**：5只火元素 - 沿矿道游荡
- **第2波**：6只火元素 + 2只熔岩傀儡
- **第3波**：4只熔岩傀儡 + 2只火焰术士（远程）
- **第4波**：1只熔岩巨兽（精英）

**Boss战**：
- **出现方式**：中央熔炉爆炸，Boss"烈焰督军"从熔岩中升起
- **登场台词**："铁与火的审判！"
- **专属技能**：
  - 陨石天降（6颗陨石+永久岩浆池）
  - 熔铸之锤（直线冲击波）
- **阶段转换**：
  - 50%血量：点燃所有熔炉（全场岩浆喷发）
  - 25%血量：Boss狂暴（攻击速度+50%）

### 3. dungeon_ice_1：冰封要塞·外围

**地形特色**：
- **布局**：L形城墙遗迹（900x700），有高台和楼梯
- **障碍物**：
  - 冰霜结晶（会缓慢扩散）
  - 崩塌城墙（掩体）
- **互动元素**：
  - 火盆（F键点燃，提供温暖buff：抗冻+20%）
  - 冰锥陷阱（踩到受20伤害+减速）
- **环境机制**：暴风雪每分钟刮起15秒，视野-50%

**波次战斗**：
- **第1波**：6只冰霜幼龙
- **第2波**：4只冰霜幼龙 + 3只冰甲骑士
- **第3波**：2只冰霜幼龙 + 4只冰甲骑士 + 1只霜巫（治疗型）
- **触发**：玩家接近高台时

**Boss战**：
- **出现方式**：天空降下冰锥，Boss"冰霜女王"传送而至
- **登场台词**："凡人的余温，终将冻结"
- **专属技能**：
  - 寒冰牢笼（困住玩家）
  - 永冻吐息（扇形冰冻）
- **阶段转换**：
  - 50%血量：冰霜结晶全场爆发（玩家需躲到火盆附近）
  - 25%血量：召唤2只冰霜幼龙

### 4. dungeon_swamp_1：迷雾沼泽·边缘

- **环境机制**：毒雾每40秒浮现，持续8秒（中毒DOT 30/秒）

**波次战斗**：
- **第1波**：8只毒蛙
- **第2波**：6只毒蛙 + 4只沼泽爬行者
- **第3波**：4只沼泽爬行者 + 2只毒液喷射者（远程）
- **第4波**：1只沼泽泰坦（精英）

**Boss战**：
- **出现方式**：中央枯树裂开，Boss"瘟疫孵化者"钻出
- **登场台词**："腐烂...即是新生..."
- **专属技能**：
  - 瘟疫脉冲（全屏毒层）
  - 孵化狂潮（召唤蛆群）
- **阶段转换**：
  - 50%血量：全场生成12个永久毒池

### 5. dungeon_void_1：虚空裂隙·入口

**地形特色**：
- **布局**：不规则虚空空间（浮空平台）
- **障碍物**：
  - 虚空裂缝（碰到受50伤害+传送）
  - 浮空岩石（可跳跃躲避）
- **互动元素**：
  - 虚空水晶（F键激活，获得短暂飞行）
  - 稳定锚点（防止被传送）
- **环境机制**：空间扭曲每45秒触发，地图旋转90°

**波次战斗**：
- **第1波**：5只虚空幼体
- **第2波**：8只虚空幼体
- **第3波**：6只虚空幼体 + 2只虚空观察者（瞬移型）
- **第4波**：3只虚空观察者 + 1只虚空扭曲者（精英）

**Boss战**：
- **出现方式**：空间撕裂，Boss"虚空行者"从裂隙中步出
- **登场台词**："现实...不过虚妄"
- **专属技能**：
  - 现实撕裂（3道裂隙）
  - 虚空回响（复制玩家技能）
- **阶段转换**：
  - 50%血量：Boss进入虚空形态（半透明）
  - 25%血量：召唤3只虚空幼体

## 技术实现要点

### 地形生成
- **方案A**：预制场景（每个副本独立.tscn）
- **方案B**：程序生成（读取配置生成TileMap）
- **推荐**：方案A（更灵活，支持复杂布局）

### 波次系统
```gdscript
# DungeonFlow.gd
var current_wave = 0
var waves = []  # 从 dungeons.json 读取

func start_dungeon(dungeon_id: String):
    waves = _load_waves(dungeon_id)
    _spawn_wave(0)

func _spawn_wave(index: int):
    var wave = waves[index]
    for enemy_config in wave.enemies:
        _spawn_enemy(enemy_config)
```

### Boss登场
```gdscript
func _trigger_boss():
    # 1. 播放动画
    boss.play_entrance_animation()
    # 2. 显示Boss血条UI
    HUD.show_boss_health(boss)
    # 3. 锁定出口
    dungeon_gate.lock()
```
