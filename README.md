## 🎯 项目核心

### 游戏玩法
- **类型**：自上而下ARPG + Roguelite
- **核心**：装备构筑深度 + 词缀系统
- **流程**：打怪 → 掉装备 → 变强 → 挑战更难副本

### 内容规模
- ✅ **6个职业**（战士/游侠/法师/刺客/骑士/死灵师）
- ✅ **5个套装**（5大古神流派）
- ✅ **8个装备部位** × **5个稀有度**
- ✅ **21个副本**
- ✅ **5种词缀效果**（吸血/点燃/中毒/冰冻/减速）

### 技术特点
- ✅ **配置驱动**：所有内容通过JSON配置
- ✅ **模块化设计**：7个核心系统
- ✅ **可扩展架构**：易于添加新内容
- ✅ **完善文档**：从设计到验收全覆盖

## 📞 常见问题

**Q: 如何运行游戏？**  
A: 双击 `project/src/project.godot` 或在Godot编辑器中打开，按F5运行

**Q: 如何修改配置？**  
A: 编辑 `project/src/config/*.json` 文件，重启游戏生效

**Q: 如何添加新装备？**  
A: 在 `project/src/config/equipment.json` 中按照现有格式添加新条目

**Q: 美术素材如何获取？**  
A: 参考 `project/src/assets/DOWNLOAD_GUIDE.md`

**Q: 发现Bug怎么办？**  
A: 记录问题详情并反馈
